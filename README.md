## 🛠️ Quickstart & Local Execution

### 1. Installation
```bash
git clone https://github.com/jackhu24-ship-it/phantom-grid-kiroween-dark-mode.git
cd phantom-grid-kiroween-dark-mode
pip install -r requirements.txt
```

### 2. Launch the Dark Night Titan TUI in your Terminal
```bash
python main.py
```

### 3. Launch Interactive Web Telemetry Console (Port 8080)
```bash
python app.py
```
Open `http://localhost:8080` in your browser.

### 4. Run Unit & Closure Tests
```bash
pytest tests/test_kiroween_closure.py -v
```

### 5. Reproduce 1,000 Chaos Benchmark
```bash
pytest 08_AuditReceipts/test_kiroween_chaos_challenge.py -v -s
```
